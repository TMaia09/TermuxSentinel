# 🛡️ Termux Sentinel

O **Termux Sentinel** é uma ferramenta leve de auditoria de segurança de rede e monitoramento local desenvolvida para rodar 100% nativamente em ambientes Linux/Android via **Termux**.

## 🚀 Funcionalidades
- **Varredura de Portas (Port Scanner):** Testa conexões em portas essenciais (21, 22, 80, 443, 8080).
- **Persistência de Dados:** Armazena o histórico de auditorias em banco de dados **SQLite**.
- **Dashboard Web:** Interface gráfica nativa em HTML/CSS servida via **Flask**.

## 🛠️ Tecnologias Utilizadas
- Python 3
- SQLite3
- Flask
- HTML5 / CSS3
- Termux (Android Linux CLI)
